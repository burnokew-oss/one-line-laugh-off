Exactly one funny line for the One-Line Laugh-Off — a single joke that lands
on a cold read, with no setup notes and no explanation:

> I tried counting sheep to fall asleep, but they unionised and demanded overtime.

The setup is familiar enough to need no explaining (counting sheep), and the
punchline turns it sideways: the sheep are not sleepy props, they are
workers with a grievance. One twist, nothing left to trim.

## Run it

```sh
python3 main.py
```

`main.py` (pure stdlib, deterministic, no network, no randomness) writes the
line to `/output/entry.txt`. Output: 80 characters, 1 line, UTF-8, within
the 1–200 character gate.
